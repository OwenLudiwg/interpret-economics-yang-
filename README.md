# 读懂经济学 · Interpret Economics

怎么从一张企业成本曲线图联想到读大学是否值得？这项中文 AI 学习技能从经济学概念、公式、理论或图形出发，查阅相关模型，挑出容易被忽略的关系，再探究它能解释哪些现实选择。有值得追问的哲学问题时，说明这个问题来自模型里的哪一步。

## 从课堂上的三条曲线说起

这个项目的灵感来自经济学课堂。老师用三条短期总成本曲线说明，不同规模的固定投入，可能适合不同的产量。起点更高（即固定成本最高）的那条曲线，在产量足够大时总成本反而可能更低。

把这层关系联系现实，在教育上：花时间提高自己的学历水平，虽然在前期需要投入更多成本，但可能让自己在日后的求职和工作中付出更低的成本。再引入一个条件：如果有人负担不起前期的学费或时间，那么图上长期可能更省的那条曲线，对他而言算不算一个真正可选的方案？这就是从数学关系走到机会与自由的一条路径。反映了一定的哲学含义

除此之外，为什么新古典经济学的几乎所有理论和主线都在说一个问题，就是鼓励竞争，减少管制。这实际上反映了西方一直以来的自由主义的哲学观念，鼓励竞争的前提是放开市场门槛，即给予个体更多的权利和自由，同时保障个体的产权神圣不可侵犯。这些实际上是政治与哲学理念在经济上的反映。

因此，这个skill旨在针对经济学中的理论与规律，把复杂的图表和公式翻译和揭示出其背后反映的现实意义和哲学内涵，帮助经济学学习者增进对经济学的理解，打破学科内外对经济学只唯数学唯公式的偏见，也希望能帮助非经济学专业的人能通过这个skill了解一些简单经济学概念的现实和哲学含义，促进经济学的传播和认可


## 怎么用

**在普通 AI 对话里试读。** 打开 [SKILL.md](interpret-economics/SKILL.md)，把文件上传到支持附件的对话，或复制其中的说明。接着输入「请按这份说明解读比较优势」。想核对教材和原论文时，使用支持联网查阅的对话环境。你也可以直接阅读这份说明，照着它分析课堂上的新概念。

**在本地 Codex 中调用。** 在本页选择 **Code → Download ZIP**，解压，找到包含 SKILL.md 的 interpret-economics 文件夹。把这个文件夹整体复制到你自己项目的 `.agents/skills/` 下。最终路径应为 `.agents/skills/interpret-economics/SKILL.md`。在该项目里打开 Codex，输入：

> 用 $interpret-economics 解读「比较优势」，找一个可以带去课堂讨论的问题。

安装位置和调用方式可参阅 [OpenAI 官方说明](https://learn.chatgpt.com/docs/build-skills)。

## 可以试试

- **一个词**　「机会成本」。只给概念，观察它会主动选择哪一条关系展开。
- **一个公式**　「解读 MV = PY。等式本身能告诉我什么？从它走到现实预测还需要哪些条件？」
- **一张图**　上传课本中的成本曲线，问「这几条曲线为什么会相交？还有哪些领域也出现这种关系？」

读完后可以追问一句：「如果改变哪个条件，刚才的联想就不成立了？」如果你发现更自然的类比，或者发现某个例子遗漏了条件，欢迎在 GitHub Issues 留下原概念、你的推理和可供核对的出处。
